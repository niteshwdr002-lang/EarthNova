EARTHNOVA — COMPLETE WEBSITE (SEPARATE FILES)
==============================================

Files included:
- index.html  : website structure and all page content
- style.css   : design, colors, responsive layout, animations
- script.js   : bottom navigation, interactions, reveal and scroll effects
- README.txt  : setup and GitHub Pages instructions

How to use:
1. Extract this ZIP file.
2. Keep all four files in the same folder.
3. Open index.html in a browser to test.
4. Upload index.html, style.css, script.js, and README.txt to the ROOT of your GitHub repository.
5. Commit the changes and open your GitHub Pages site.

Important:
Do not upload only index.html. The CSS and JavaScript files must be uploaded beside it
so that the design, animations and bottom navigation work correctly.
No build tools or external libraries are required.
